# UC-02 — User Profile Management
> **Feature ID:** `feat-auth`
> **Actor:** User

## Mô tả kịch bản Use Case
1. User đăng nhập thành công vào hệ thống.
2. User điều hướng tới trang thông tin cá nhân.
3. Hệ thống hiển thị các thông tin: Email, Họ tên, Số điện thoại, Địa chỉ, Số dư khả dụng.
4. User sửa Họ tên, Số điện thoại, bấm "Lưu".
5. Hệ thống xác thực đầu vào, cập nhật database và phản hồi thành công.
