# Documentation Archive

Thư mục này lưu tài liệu lịch sử để tra cứu nguồn gốc thay đổi.

- Nội dung có thể không còn khớp source code, API hoặc database.
- Không dùng archive làm source of truth.
- Không chỉnh sửa archive để mô tả trạng thái hiện tại; hãy cập nhật tài liệu sống tương ứng.
- Tài liệu cũ sai stack được giữ để bảo toàn lịch sử, không phải hướng dẫn triển khai.

Tài liệu hiện hành bắt đầu tại [Documentation Index](../index.md).
